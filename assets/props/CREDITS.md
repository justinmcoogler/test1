# Nature Props — attribution

Static 3D forage props (mushrooms, flowers, rocks, stick bundles, a stump)
converted from the **Nature Props Pack 2 (1.21.11+)** Blockbench models, used
as harvestable world decoration.

- Source: "Nature Props Pack 2" (Blockbench `.bbmodel` assets, uploaded by the
  project owner for use in Sproutlands).
- Geometry + textures are embedded per-prop in `js/gfx/proppack.js`, generated
  by `tools/import-props.mjs`.

If you redistribute this project, verify the pack's own license permits it and
keep this credit.
