# The `mob` file format (v1)

One JSON file = one complete creature: box model, skin texture, animations,
combat stats, drops, and world-spawn rules. Drop files into `mobs/` and list
them in `mobs/manifest.json` — they load at boot. At runtime you can also call
`window.__game.importMob(json)` and preview with
`window.__game.spawnMobNear('your_mob_id')`.

The working reference file is [`mobs/glimmerfox.json`](../mobs/glimmerfox.json)
(generated by `node tools/make-sample-mob.mjs`).

## Conventions

- **Units**: world blocks (a player is 1.8 tall, a boar ~0.9). Y is up.
- **Facing**: the creature looks toward **+Z** ("south" faces are the front).
- **Texture**: a detailed painted atlas, any square image up to **1024×1024**
  (AI-generated PNGs work great); the engine stores it at up to **512²**.
  Author at **64 texels per block** ("64×", 4× Minecraft's default) — shade
  faces, add material texture, paint the face. `(0,0)` is top-left, and all UV
  rects are written in the source image's own pixel coordinates. See
  `docs/MOB_BUILDER_PROMPT.md` for the atlas-sizing math.
- **Angles**: degrees. **Times**: seconds.
- **Sizes**: ≤ 24 parts, ≤ 64 boxes total, each box dimension `0 < size ≤ 3`.
- `id`: snake_case, 3–32 chars, must not collide with built-in creatures.

## Top-level shape

```json
{
  "format": "mob",
  "version": 1,
  "id": "glimmer_fox",
  "label": "Glimmer Fox",
  "scale": 1.0,
  "texture": { ... },
  "parts": [ ... ],
  "animations": { ... },
  "stats": { ... },
  "drops": [ ... ],
  "spawn": { ... }
}
```

## `texture` — the skin

Three ways to supply it (full-color, used as-is, lit by the engine's face
shading). An embedded PNG data URI is the recommended export — it keeps the
mob as a single file and works with any image source (e.g. ChatGPT image gen):

```json
{ "dataUri": "data:image/png;base64,..." }                    // any size ≤ 1024², recommended
{ "file": "glimmer_fox.png" }                                  // sidecar image in the mobs/ folder
{ "width": 64, "height": 64, "rgbaBase64": "<raw RGBA rows>" } // raw pixels; width/height required
```

Images larger than 512² are averaged down to 512² on the GPU; pixel art ≤512
is kept pixel-perfect. A 256² atlas covers ~16 block² of surface at 64×, a
512² atlas ~64 block² (enough for a boss) — keep the atlas ≤ 512². If `width`/`height` are given with `dataUri`/`file`, UV
rects are interpreted against that declared size; otherwise against the
image's natural size.

## `parts` — the model

Parts are named groups of boxes forming a hierarchy (like Minecraft/Blockbench
bones). Each part rotates around its own `pivot`; children inherit their
parent's motion.

```json
{
  "id": "head",
  "parent": "body",            // optional; must reference an earlier-declared part id
  "pivot": [0, 0.62, 0.48],    // rotation origin, model space
  "boxes": [
    {
      "from": [-0.19, 0.5, 0.42],   // min corner [x, y, z]
      "size": [0.38, 0.36, 0.38],   // [width, height, depth]
      "uv": {                       // texture rect per face: [x, y, w, h] in pixels
        "north": [32, 0, 12, 12],   // back  (−Z)
        "south": [44, 0, 12, 12],   // front (+Z) — faces go here
        "east":  [32, 0, 12, 12],   // +X
        "west":  [32, 0, 12, 12],   // −X
        "up":    [32, 0, 12, 12],
        "down":  [32, 0, 12, 12]
      }
    }
  ]
}
```

`uv` may also be a single `[x, y, w, h]` applied to all six faces, or an object
with an `"all"` key plus overrides. Each rect is stretched across its face; the
rect's top edge maps to the face's top edge.

## `animations` — keyframed poses

Reserved names the engine plays automatically: **`idle`** (always), **`walk`**
(while moving), **`attack`** (one-shot when the creature strikes). All optional;
missing states fall back to `idle`, then to a static pose.

```json
"walk": {
  "length": 0.6,               // seconds
  "loop": true,                // default true; attack should use false
  "parts": {
    "leg_fl": { "rotate":    [ [0, [28,0,0]], [0.3, [-28,0,0]], [0.6, [28,0,0]] ] },
    "body":   { "translate": [ [0, [0,0,0]],  [0.3, [0,0.05,0]], [0.6, [0,0,0]] ] }
  }
}
```

- `rotate` keyframes: `[timeSec, [xDeg, yDeg, zDeg]]`, applied around the
  part's pivot in Z·Y·X order. Positive X pitches the front downward.
- `translate` keyframes: `[timeSec, [dx, dy, dz]]` in blocks.
- Interpolation is linear; looping animations should end where they begin.

## `stats` — how it fights

```json
{
  "hp": 14, "atk": 4, "speed": 8,          // required
  "acc": 62, "evasion": 16, "armor": 0,    // hit chance vs you / dodge / damage soak
  "moveRange": 4,                          // tactical-mode tiles per turn (0 = stationary)
  "behavior": "defensive",                 // "passive" | "defensive" | "aggressive"
  "aggroRange": 5,                         // blocks (aggressive only)
  "ranged": false, "range": 4,             // ranged attacker + its reach
  "element": null, "weak": ["fire"], "resist": [],   // fire | water | ice | nature | shadow
  "tier": 0,                               // 0 starter … 3 endgame (scales coin drops)
  "xp": 22, "huntXp": 16,                  // combat XP value; huntXp only for beasts
  "respawn": 90,                           // seconds after being slain
  "desc": "One-line flavor text.",
  "recommend": "Shown by Inspect."
}
```

## `drops` and `spawn`

```json
"drops": [ { "item": "sinew", "qty": [1, 2], "chance": 0.8 } ],
"spawn": {
  "biomes": ["greenwood_plains", "ancient_forest"],
  "density": 0.0012,
  "nightOnly": false,      // optional: spawns only after dark, fades at dawn
  "packSize": [2, 3]       // optional: spawn in groups of min..max (1-4)
}
```

- `item` must be an existing item id (see `js/game/items.js`).
- `density` is per surface block per chunk — 0.001–0.003 is a sensible range.
- Valid biomes: `greenwood_plains`, `ancient_forest`, `misty_wetlands`,
  `rocky_highlands`, `sunbaked_badlands`, `frostbound_tundra`,
  `volcanic_wastes`, `corrupted_wilds`, `coastal_shores`.
- `stats.shinyChance` (0–0.2, default 0.015) controls the rare gilded
  variant: golden shimmer, double drops, triple coins, double XP.

## Validation

The loader rejects files with a specific error (bad format/version, id
collisions, unknown parents, missing textures, wrong texture size, unknown
item/biome references, malformed keyframes). Errors appear in the browser
console prefixed `[mobs]`.
